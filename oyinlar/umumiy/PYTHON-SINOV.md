# Python blokini bolalarda sinash: varaqa

QOIDALAR §10.6 — oʻyin bolalarga oʻynatib koʻriladi, natijaga qarab tuzatiladi.
Bu varaqa **oʻqituvchi uchun**: nimaga qarash kerak, nimani soʻrash kerak.

**Nechta bola:** 2–3 ta yetarli. **Yosh:** 12–16. **Qurilma:** kompyuter, klaviatura bilan.
**Vaqt:** bir bolaga 40–50 daqiqa (27–30-oʻyinlar).

---

## 1. Sinovdan oldin (5 daqiqa, yozma)

Bola hali oʻynamasdan javob bersin. Maqsad — keyin solishtirish.

1. `print("Salom")` nima qiladi deb oʻylaysan?
2. Bu nima chiqaradi: `print(2 + 3)` va `print("2 + 3")`?
3. `x = 5` va keyin `x = x + 1` boʻlsa, `x` nechaga teng?
4. `17 // 5` va `17 % 5` nima beradi?
5. Dastur qanday qilib "agar… boʻlsa" deb qaror qabul qiladi?

Javoblarni saqlab qoʻying. Oʻyindan keyin **oʻsha savollarni qayta** bering.

## 2. Oʻynayotganda: nimaga qarash kerak

Bolaga **yordam bermang** (faqat qotib qolsa). Kuzating va belgilang:

| Nimaga qarash | Nega muhim |
|---|---|
| Qavs/qoʻshtirnoqni yopishni unutadimi, xato xabarini **oʻqiydimi** | 27-oʻyinning asosiy maqsadi |
| Xato xabari chiqqanda **qoʻrqadimi** yoki oʻqib tuzatadimi | Ohang toʻgʻri tanlanganmi |
| `⏭ Qadam` tugmasini bosadimi yoki oʻtkazib yuboradimi | Qadam-baqadam panel ishlayaptimi |
| Kuzatuv jadvalini toʻldirishda qaysi ustunda adashadi | 29-oʻyinning eng qiyin joyi |
| `input()` matn qaytarishini tushunadimi | 29-oʻyin, 3-bosqich |
| Otstupni qoʻlda qoʻyadimi yoki Tab bosadimi | Muharrir qulaymi |
| Matnni **oʻqiydimi** yoki faqat kodga qaraydimi | Matn uzun boʻlib qolgan boʻlishi mumkin |
| Qaysi joyda **zerikadi** (koʻzi olib qochadi) | Oʻsha sahna uzun |
| Qaysi joyda **kulib yuboradi yoki hayratlanadi** | Oʻsha yerni koʻpaytirish kerak |

**Vaqtni yozib boring:** har bosqich necha daqiqa ketdi. 10 daqiqadan oshsa — bosqich uzun.

## 4. Oʻquv maqsadlari boʻyicha tekshiruv

Har oʻyinning `DIZAYN.md` idagi "Oʻquv maqsadlari" — tekshiriladigan roʻyxat. Qisqasi:

- **27 Birinchi buyruq:** `print` yozadi · qoʻshtirnoq ichi/tashqarisi farqini aytadi · xato xabaridan satr raqamini topadi.
- **28 Sonlar ustaxonasi:** `//` va `%` ni hayotiy misolda tushuntiradi · `/` doim kasr berishini biladi · amallar tartibini aytadi.
- **29 Nomli qutilar:** `x = x + 1` ni tushuntiradi · kuzatuv jadvalini toʻldiradi · `int(input())` nega kerakligini aytadi.
- **30 Ikki yoʻl:** otstup blokni belgilashini koʻrsatadi · `elif` tartibi muhimligini aytadi · `=` va `==` farqini biladi.

Bolaning **oʻz soʻzi bilan** aytishi muhim — yod olgan taʼrif emas.
