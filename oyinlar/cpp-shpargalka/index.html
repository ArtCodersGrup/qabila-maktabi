Tuzoqlar — eng koʻp uchraydigan xatolar

  • Butun boʻlish: 7 / 2 → 3. Kasr kerak boʻlsa: 7 / 2.0.
  • Manfiy sonlar: C++ da -7 / 2 = -3 va -7 % 3 = -1 (Pythonda −4 va 2).
  • Toshib ketish: int ga sigʻmagan javob jim buziladi, xato chiqmaydi. Shubha boʻlsa — long long.
  • Massiv chegarasi: a[n] ga yozish xato bermaydi, lekin javobni buzadi.
  • = va ==: if (x = 5) — tayinlash, shart doim rost.
  • Qavs: qavssiz if va for ga faqat keyingi bitta satr kiradi.
  • Boʻsh tana: for (…); — nuqtali vergul siklni boʻsh qoldiradi.
  • int ga kasr: int a = 2.9; → 2 (kesiladi, yaxlitlanmaydi).

Olimpiadaning birinchi bosqichi uchun shu yetadi

int n;
cin >> n;
int a[100005];
for (int i = 0; i < n; i++) cin >> a[i];

long long s = 0;
int eng = a[0];
for (int i = 0; i < n; i++) {
    s += a[i];
    if (a[i] > eng) eng = a[i];
}
cout << s << " " << eng << "\n";

Yigʻindi uchun long long olinadi — sonlar koʻp boʻlsa int toshib ketadi. Bitta oʻtishda yigʻindi, eng katta, eng kichik va sanoqni topish — birinchi bosqich masalalarining yarmi shu naqshda yechiladi.
