# 45 — Kaptarxona: ish rejasi

Dizayn: [`DIZAYN.md`](DIZAYN.md). Blok rejasi: [`../umumiy/KOMBINATORIKA-BLOK.md`](../umumiy/KOMBINATORIKA-BLOK.md).

- [x] **1. Mantiq** — `kafolat`, `kerak`, Dirixle savollari (5 xil), «kamida nechta kerak» savollari, kod masalalari, `SINOV` (`k^n`).
- [x] **2. Testlar** — 11 ta: **hamma joylashuv** boʻyicha kafolatning buzilmasligi, `(g−1)·k < n ≤ g·k`, `k·(m−1)+1` ning chegarasi, namunali yechimlar, `n // k` kabi xato yechimning oʻtmasligi.
- [x] **3. Ekran** — bosiladigan uyalar (sudrash yoʻq), «eng yomon holat» chiplari, joylashuvlar jadvali.
- [x] **4. Sahnalar** — bola ikki marta oʻzi joylaydi; qoida; paypoqlar; kod; `k^n` jadvali.
- [x] **5. Bosh sahifa va oflayn** — `bosh.js`, ikonka `kaptar`, `sw.js` (`v63`).
- [x] **6. Tekshiruv** — testlar yashil; brauzerda oxirigacha oʻynaldi, konsol toza; «natija» mashqi toʻgʻri javobni qabul qilishi alohida tekshirildi.

## Qoladi

- Masalalar bankiga `kombinatorika` tegi bilan masalalar (muallif roziligi bor).
- Muallif blokni (41–45) koʻrib chiqadi.
